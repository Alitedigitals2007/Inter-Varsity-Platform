# League of Rounds Configuration

## Default Format
League of Rounds (LEAGUE_ROUNDS) is now the default competition format.

## How It Works
1. After selecting at least 2 schools, select the number of rounds
2. Questions are automatically assigned from all active questions in the bank
3. GM can cycle between categories during gameplay
4. Scores accumulate per category across all rounds

## Features
- `categoryOrder` is set in match config for GM category control
- Multiple categories can be enabled in a single match
- Cumulative scoring per category visible in leaderboard
- GM advances with \"Next Category\" button in dashboard
